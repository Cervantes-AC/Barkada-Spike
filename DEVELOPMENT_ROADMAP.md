# BARKADA SPIKE — Development Roadmap

10 milestones. Core gameplay first; menus/cosmetics/online last.

| Milestone | Focus | Status |
|---|---|---|
| M1 — Project Setup | Godot + VS Code config, folder structure, main scene, volleyball court, main attacker movement & jump | ✅ Complete |
| M2 — Main Attacker (+ mobile controls) | Move, jump, land, keyboard + mobile touch controls | ✅ Complete |
| M3 — Ball Physics | Gravity, velocity, collision, net, floor, boundaries | ✅ Complete |
| M4 — Attack Mechanics | Serve, spike, attack direction, timing grades (PERFECT/GREAT/GOOD/LATE/MISS), effects | ✅ Complete |
| M5 — Automatic Teammates | Setter AI, defender AI, ball prediction, receiving, setting, auto-block | ✅ Complete |
| M6 — Complete Match | Opponent AI, scoring, volleyball rules, match phases, match results | ✅ Complete |
| M7 — Offline Game | Story Mode, Quick Match, Practice, 5 tournaments, characters, rewards, save system | ✅ Complete |
| M8 — UI and Presentation | Main menu, character selection, tournament selection, HUD, sound, animation, effects | ✅ Complete |
| M9 — Online Multiplayer | Host/join, synchronization, disconnect handling, two-device testing | ✅ Complete |
| M10 — Finalization | Android export, performance testing, bug fixes, docs, GitHub repo, demo video | ✅ Complete |

Online multiplayer is developed ONLY after offline gameplay is stable (M6/M7).
